# Google Docs

Tato část popisuje technické nastavení dokumentu v Google Docs: stránku, styly, nadpisy, odstavce, seznamy, tabulky, obrázky, automatický obsah a číslování stran.

!!! warning "Ověřte s vedoucím práce"
    Google Docs je v této části výchozí nástroj pro nácvik. Pokud budete pracovat v MS Wordu, použijte závazné požadavky GASOŠ stejně, ale konkrétní postupy v aplikaci se budou lišit.
