# Odrážkové a číslované seznamy

## Cíl

Seznamy budou skutečné seznamy Google Docs, ne ručně napsané znaky.

## Kdy který seznam použít

- Odrážkový seznam použijte, když pořadí položek není podstatné.
- Číslovaný seznam použijte pro postup, pořadí, prioritu nebo počet kroků.

## Postup

1. Každou položku napište do samostatného odstavce.
2. Označte položky.
3. Klikněte na **Odrážkový seznam** nebo **Číslovaný seznam**.
4. Vyberte jednotný typ značky nebo číslování.
5. Pomocí pravítka nebo nastavení odsazení sjednoťte začátek textu.
6. Odstraňte prázdné položky vzniklé nadbytečným Enterem.

## Více úrovní

**Tab** nebo **Zvětšit odsazení** přesune položku na nižší úroveň. **Shift+Tab** nebo **Zmenšit odsazení** ji vrátí výš.

!!! note "Technická poznámka"
    Google Docs nemá plnohodnotný pojmenovaný styl seznamu jako Word. Vytvořte vzorový seznam a další seznamy upravujte podle něj.
