# Automatické popisky a seznamy

## Cíl

Popisky tabulek, obrázků a grafů budou připravené tak, aby je mohl zpracovat školní Apps Script.

!!! note "Technická poznámka"
    Google Docs nemá stejně robustní systém automatických titulků a seznamů obrázků jako Word. V tomto projektu má mezeru vyplnit vlastní Apps Script.

## Očekávaný pracovní postup

1. Vložte tabulku, obrázek nebo graf.
2. Vytvořte popisek na samostatném řádku.
3. Použijte typ označení očekávaný skriptem: `Tab.` pro tabulky a `Obr.` pro obrázky a grafy.
4. Nepište čísla ručně, pokud je doplňuje skript.
5. Spusťte aktualizaci popisků.
6. Spusťte aktualizaci seznamů nebo společný příkaz.
7. Zkontrolujte návaznost čísel a funkčnost odkazů.

!!! warning "Ověřte s vedoucím práce"
    Přesná vstupní syntaxe popisku a názvy příkazů se musí doplnit podle finálního otestovaného skriptu.

## Vzhled seznamů

Seznam obrázků a grafů, seznam tabulek a případně seznam příloh mají začínat na samostatných stránkách. Položky mají používat běžné černé písmo bez nechtěného tučného zvýraznění.
