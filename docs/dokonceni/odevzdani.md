# Odevzdání

## Cíl

Připravíte výsledný soubor i pracovní materiály tak, aby bylo možné práci odevzdat a později dohledat zdroje.

## Před odevzdáním

1. Ověřte aktuální termín a místo odevzdání.
2. Pojmenujte výsledný soubor podle aktuálních pokynů školy.
3. Otevřete PDF a projděte všechny stránky.
4. Archivujte editovatelný dokument.
5. Archivujte sbírku nebo knihovnu Zotera.
6. Uložte podklady, data a přílohy používané v práci.

!!! warning "Ověřte s vedoucím práce"
    Organizační pokyny, termíny a přesné pojmenování souboru se mohou měnit. Vždy ověřte aktuální školní zadání.
