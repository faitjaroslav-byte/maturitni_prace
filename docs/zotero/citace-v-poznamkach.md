# Citace v poznámkách pod čarou

## Cíl

Vyzkoušíte poznámkový citační systém bez ručního zakládání poznámek.

## Styl

Pro praktický test byl použit styl:

> `ISO-690 (full note, Čeština)`

## Vložení citace

1. Napište tvrzení a koncové interpunkční znaménko.
2. Pokud se odkaz vztahuje k celé větě, umístěte kurzor za znaménko.
3. Nevkládejte předem ruční poznámku pod čarou.
4. Zvolte **Zotero -> Add/Edit Citation**.
5. Vyberte zdroj a případně stránku.
6. Zotero vytvoří horní index i text poznámky.

!!! warning "Ověřte s vedoucím práce"
    Školní manuál popisuje zkrácenou poznámku a úplný záznam v seznamu literatury. Před finálním doporučením je nutné ověřit, zda zvolený CSL styl odpovídá požadavkům školy.
