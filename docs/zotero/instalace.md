# Instalace Zotera

## Cíl

Nainstalujete Zotero tak, aby šlo vkládat citace přímo do Google Docs.

## Součásti Zotera

- **Zotero Desktop** je hlavní aplikace a lokální knihovna zdrojů.
- **Zotero Connector** je rozšíření prohlížeče pro ukládání zdrojů a integraci s Google Docs.
- **Webová knihovna Zotera** je doplňkový přístup ke knihovně přes web.

!!! note "Technická poznámka"
    Pro vkládání a úpravu citací v Google Docs musí být Zotero Desktop nainstalované a spuštěné.

## Postup

1. Stáhněte a nainstalujte Zotero Desktop z oficiálního webu.
2. Nainstalujte Zotero Connector do používaného prohlížeče.
3. V Safari aktivujte rozšíření, pokud je součástí desktopové instalace.
4. Spusťte Zotero Desktop.
5. Otevřete Google Docs a ověřte, že se objevila nabídka **Zotero**.
6. Při prvním použití povolte propojení s dokumentem.

## Kontrolní bod

- [ ] Zotero Desktop je spuštěné.
- [ ] Connector je v prohlížeči povolený.
- [ ] V Google Docs je nabídka **Zotero**.
