# Řešení problémů se Zoterem

## V Google Docs chybí nabídka Zotero

Zkontrolujte, zda je spuštěné Zotero Desktop, povolený Connector a otevřený podporovaný prohlížeč. Potom restartujte Zotero i prohlížeč.

## Connector nevidí desktopovou aplikaci

Spusťte Zotero Desktop a ověřte rozšíření v prohlížeči. Pokud problém trvá, zkontrolujte nastavení Connectoru.

## Zdroj nelze najít podle identifikátoru

Ověřte, že používáte identifikátor konkrétního zdroje. ISSN označuje celý časopis, ne konkrétní článek.

## Citace se nezměnila po změně stylu

Otevřete **Zotero -> Document Preferences**, vyberte styl a potom použijte **Refresh**.

## Bibliografie se neaktualizovala

Zkontrolujte, zda jsou citace stále dynamická pole Zotera. Pokud byl použit příkaz **Unlink Citations**, propojení je odstraněné a nejde jej jednoduše obnovit.

## Chybná metadata

Opravte záznam v Zotero Desktop, ne hotovou citaci v dokumentu. Potom použijte **Refresh**.
