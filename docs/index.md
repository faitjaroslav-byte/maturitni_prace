!!! warning "Ověřte s vedoucím práce"

## Co se naučíte

- rozlišit typ práce a vybrat odpovídající skladbu kapitol;
- nastavit v Google Docs stránku A4, okraje, styly a odstavce;
- používat automatický obsah, číslování nadpisů, popisky a seznamy;
- spravovat zdroje v Zoteru a nevkládat citace ručně;
- zkontrolovat dokument před exportem do PDF nebo PDF/A.

## Otevřené podklady

!!! info "Technická poznámka"
    V repozitáři zatím chybí finální otestovaný Apps Script a aktuální školní šablona. Kapitoly o automatizaci proto popisují bezpečný postup a označují místa, která je nutné doplnit podle skutečného skriptu.
