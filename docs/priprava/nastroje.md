# Potřebné nástroje

## Cíl

Připravíte si prostředí, ve kterém můžete dokument psát, formátovat, citovat a bezpečně obnovit po chybě.

## Co budete potřebovat

- účet Google;
- Google Docs v podporovaném prohlížeči;
- Zotero Desktop;
- Zotero Connector v prohlížeči;
- volitelně bezplatný účet Zotero.org pro synchronizaci.

!!! note "Technická poznámka"
    Webová knihovna Zotera je užitečná pro prohlížení a sdílení záznamů, ale pro vkládání citací do Google Docs je potřeba nainstalované a spuštěné Zotero Desktop.

## Příprava Google Docs

1. Otevřete Google Disk.
2. Vytvořte nový dokument nebo kopii školní šablony.
3. Soubor ihned smysluplně pojmenujte.
4. Ověřte, že máte právo dokument upravovat.
5. Před větším automatickým zásahem vytvořte pojmenovanou verzi nebo kopii dokumentu.

!!! tip "Doporučený postup"
    Historie verzí je základní bezpečnostní síť. Před prvním spuštěním skriptu je ale vhodnější kopie nebo pojmenovaná verze, protože skript může provést mnoho změn najednou.

## Příprava Zotera

1. Nainstalujte Zotero Desktop.
2. Nainstalujte Zotero Connector.
3. Spusťte Zotero Desktop.
4. Otevřete Google Docs.
5. Ověřte, že se v dokumentu zobrazuje nabídka **Zotero**.

## Kontrolní bod

- [ ] Dokument je založený nebo zkopírovaný ze školní šablony.
- [ ] Vím, kde najdu historii verzí.
- [ ] Zotero Desktop je spuštěné a v Google Docs je vidět nabídka **Zotero**.
